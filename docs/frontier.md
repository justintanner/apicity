## Refresh

Run `pnpm run fetch:frontier` to download every leaderboard into
`scripts/frontier/<type>/leaderboard.json` (name types to refresh only those,
`--dry-run` to preview), or paste a new leaderboard by hand. The script gives a
new model an empty list in `scripts/frontier/<type>/endpoints.json` and drops a
model that left the board; fill in the empty lists so every model has an
endpoint list or an explicit empty list. A dedicated leaf sets pricingKey to its
PRICING key (for fal, the upstream endpoint id) or "unpriced". A shared callable
prices by modelId. Keep ranks contiguous from 1 and stop at 10, or list every
model when the board has fewer than 10. Bump the capture date, run `pnpm run
gen:frontier` and `pnpm run doc-gen`, and commit the JSON with the regenerated
registry and this file. A `t2v` or `i2v` refresh also re-derives `r2v`, which
the script does from the models already in the `r2v` endpoint map: list the
models of both top 10 that have a reference-to-video endpoint, better Elo first,
each with that Elo and that board's creator. The generator refuses a derived
list that no longer matches its sources. `pnpm run fetch:frontier` is the only
code that downloads a leaderboard, and only when a person runs it: nothing in
the build, tests, or CI may download a leaderboard or a price. An adapter row
sets adapter to the upstream selector and note to the limitation that selector
carries.
