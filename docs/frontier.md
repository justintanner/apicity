## Refresh

Paste a new leaderboard into `scripts/frontier/<type>/leaderboard.json` and
update `scripts/frontier/<type>/endpoints.json` so every model has an endpoint
list or an explicit empty list. A dedicated leaf sets pricingKey to its PRICING
key (for fal, the upstream endpoint id) or "unpriced". A shared callable prices
by modelId. Keep ranks contiguous from 1 and stop at 10, or list every model
when the board has fewer than 10. Bump the capture date, run `pnpm run
gen:frontier` and `pnpm run doc-gen`, and commit the JSON with the regenerated
registry and this file. A `t2v` or `i2v` refresh also re-derives `r2v`: list the
models of both top 10 that have a reference-to-video endpoint, better Elo first,
each with that Elo and that board's creator. The generator refuses a derived
list that no longer matches its sources. Nothing in code, tests, or CI may
download a leaderboard or a price.
